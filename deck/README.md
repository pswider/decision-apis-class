## Notes

- The deck is built on a theme, layouts and placeholders, so it can be
  restyled in one place. Headings are Georgia and body text is Segoe UI, the
  fallbacks named in the [style guide](../docs/style-guide.md).
- Slide 21 is a native PowerPoint chart. The numbers can be edited in place.
- Slides 2 and 26 are the conference organizers' sponsor and session
  evaluation slides.
- Every number on the slides comes from the [main page](../README.md), which
  says where each one came from and what was not verified. The real results
  are model output that no person has reviewed yet.
- Independent class materials. Not affiliated with, sponsored by or endorsed
  by Microsoft, Google or TypeSafe AI.
